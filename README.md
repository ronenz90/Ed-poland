# עדים במדים · מסע לפולין (11–15.10.2026)

דף לו"ז אינטראקטיבי עם קודי לבוש, נסיעות, החלפות בגדים ורשימת ציוד.
מזג האוויר מתעדכן אוטומטית כל 3 שעות. סימוני הציוד נשמרים רק בדפדפן של כל משתמש.

## מבנה
```
index.html                      הדף כולו (עיצוב, לו"ז, לוגיקה)
scripts/fetch_weather.py        שולף תחזית שעתית מ-Open-Meteo וכותב weather.json
.github/workflows/deploy.yml    בונה ומפרסם ל-GitHub Pages, בכל push ובכל 3 שעות
```

## העלאה (חד־פעמי, כ־5 דקות)
1. ב-GitHub: **New repository**. שם לבחירתך, **Public** (ב-Pages החינמי חובה ציבורי).
2. מעלים את שלושת הפריטים לעיל, עם מבנה התיקיות כמו שהוא (כולל התיקייה `.github`).
   בדפדפן: **Add file → Upload files** וגוררים את התיקיות. או בטרמינל:
   ```
   git init -b main && git add . && git commit -m "init"
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. **Actions → Deploy site with fresh weather → Run workflow** (או כל push חדש).
5. אחרי כדקה האתר זמין ב: `https://<user>.github.io/<repo>/`

## איך זה עובד
- ה-workflow רץ בכל push, בכל 3 שעות (cron, שעון UTC) ובהפעלה ידנית.
  בכל ריצה הוא שולף תחזית ל-5 אתרים, שומר `weather.json` בתוך האתר שמתפרסם ומפרסם מחדש.
  אין commits חדשים בריפו.
- הדף קורא את `weather.json` בכל פתיחה. אם הקובץ חסר או שהשליפה נכשלה, הדף ממשיך להציג
  את התחזית המוטמעת בו. מוצג גם "עדכון אחרון" בתחתית.
- נקודות התחזית (בקובץ `scripts/fetch_weather.py`): ורשה, אזור בלז'ץ (יוזפוב ובלז'ץ), לובלין (מיידנק), קרקוב, אושוויץ.
- התחזית של Open-Meteo מגיעה עד 16 יום קדימה, ולכן 11–15 באוקטובר כבר מכוסים.

## שמירה מקומית
סימוני הציוד, התצוגה האחרונה, בחירת השעון ומצב כהה/בהיר נשמרים ב-`localStorage` בלבד.
הם לא עוברים בין מכשירים ולא נשלחים לשרת. גלישה פרטית או ניקוי נתוני אתר מוחקים אותם.
